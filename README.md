# Personal Introduction Program

## Project Overview
This project is a beginner Python program that collects user information and displays a personalized welcome message.

## What I Learned
- Python variables
- Using input() for user input
- Using print() for output
- Basic program structure
- f-strings for formatted output

## Setup Instructions
1. Install Python
2. Download the project files
3. Run the program using:

python personal_intro.py

## Program Features
- Asks user name
- Asks user age
- Asks user hobby
- Displays a friendly introduction message

## Example Output

What is your name? Alex  
How old are you? 21  
What is your favorite hobby? Coding
